# Approved Ribbon reference

`approved-paper-motion.html` is the unchanged owner-approved visual demo.
Its SHA-256 is `ba17f515dd91304e6f164f6131ad6c3c124c27792f3efb1d60ed2a1aba868308`. The Ribbon branch of `paperPoints`,
`drawMesh`, and `drawPaper` supply the mesh, face lighting/order, and alpha
reference respectively. Browser texture colors and the mocked window are
illustrative; the app must use its own selected bundled texture and lamp.

`ribbon-demo.json` was generated by executing the original JavaScript
`paperPoints("ribbon", progress)` at progress values 0, .1, .2, .43, .45,
.7, .9, and 1, with the reference's 326 × 212 sheet. The demo's calculated
center is subtracted from each vertex to isolate local mesh geometry. Face
normals, lighting, average depth and sorting use `drawMesh`'s calculations.
The alpha follows `drawPaper`'s terminal fade. No values are calculated by
the Swift implementation. Fixture SHA-256: `59ac73628332289941fc6546eb348fc4403848f726a9e0c605d7d178b6c42a36`.

Tests compare every vertex and each triangle's lighting/depth by identity.
They compare sorted depths separately because JavaScript and Swift math
libraries can reverse triangles whose depths differ only in the last bit.
The tolerances are 1e-12 for state and 1e-9 for geometry and lighting.

The reference is kept here for independent inspection and regeneration; it
is excluded from the app and does not add a runtime or package dependency.
